プライバシーポリシー

無限そば道・斬 ～蕎麦切り修行～（以下「本ゲーム」）

1. この方針について

本ゲームの作者（個人）は、本ゲームを遊ぶ方の情報を、このページに書いた範囲でだけ扱います。本ゲームは、Web版（ブラウザ）と、それをそのまま表示する Android アプリで同じ内容です。

2. 端末の中だけに保存する情報

自己ベスト、称号、図鑑、そば猪口コイン、そば札、着せ替え、名前（表示名）、クイズの成績、リズム修行・斬の記録（コースごと）、効果音・BGM・演出・師匠のイタズラの設定などのゲームの記録は、お使いの端末のブラウザ（アプリ）の中に保存します。アカウントにログインしない限り、これらが端末の外に送られることはありません。リズム修行・斬の「試し切り」で測ったずれ補正の値は、端末やイヤホンごとに違うため、その端末の中だけに保存し、ログインしても送りません。

3. アカウントを作ったときに保存する情報（任意）

マイページでアカウントを作ると、端末どうしで記録を同期するために、次の情報をサーバーに保存します。アカウントを作らなくても、本ゲームはすべて遊べます。

  • ユーザー名（ご自身で決めた3〜16文字の名前）
  • パスワードから作った値（パスワードそのものは保存も送信もしません。端末の中で SHA-256 で変換してから送り、サーバーではさらに塩を加えて PBKDF2 で変換したものだけを保存します）
  • ゲームの記録（上の2. と同じ内容。名前（表示名）を含みます。コインとそば札を端末どうしで正しくまとめるため、端末ごとに付けたランダムな記号を含みます。この記号から個人や端末の種類はわかりません）
  • ログインを続けるための符号（トークン。180日で無効になります）

保存先は、Cloudflare, Inc. のサービス（Cloudflare Workers・Workers KV）です。通信はすべて暗号化（HTTPS）されます。

3-2. 番付に参加したときに公開する情報（任意）

ログイン中に「番付」で「番付に参加する」を選んだ端末からだけ、リズム修行・斬を1曲遊ぶたびに次の情報をサーバーに送ります。参加しなければ送りません。

  • 番付に載せて、ほかのプレイヤーにも見えるもの：表示名（マイページの名前。ユーザー名は載せません）、コース、得点、完成度、最大コンボ、Perfectの数、師匠のイタズラの有無。コースごとに「今週」と「全期間」の上位50人までです。
  • 確かめるためだけに使うもの：その1曲の判定の記録（どの拍で、どれだけずれて切ったか）。サーバーで得点を計算し直して確かめるために使い、保存しません。

番付は参考記録です。「今週」の番付は3週間でサーバーから消えます。参加をやめる（「番付に参加する」を外す）か、アカウントを削除すると、番付からあなたの記録を消します。

4. 集めない情報

  • メールアドレス、本名、電話番号、住所、位置情報、連絡先、写真などは集めません。
  • 広告、アクセス解析、広告IDの取得は行っていません。
  • アプリ内課金はありません（ガチャはゲーム内のコインだけで引けます）。

5. 通信のときに相手のサービスに届く情報

本ゲームを開くと、ページの配信（GitHub Pages・GitHub, Inc.）、文字の表示（Google Fonts・Google LLC）、同期（Cloudflare）のために、各サービスにお使いの端末の IP アドレスやブラウザの種類などが、ふつうのWebの通信と同じように届きます。作者はこれらを使って個人を特定したり追跡したりしません。各サービスでの扱いは、それぞれのプライバシーポリシーに従います。

6. 使う目的と、ほかの人への提供

3. の情報は、ログインと、端末どうしの記録の同期のためだけに使います。3-2. の情報は番付のためだけに使い、番付に載せるもの以外はほかの人に見せません。法令に基づく場合を除き、ほかの人や会社に提供・販売することはありません。

6-2. 共有と要望の送り先

  • 友達に共有：お使いの端末の共有機能、またはクリップボードへのコピーを使います。共有した相手や共有先の情報を、本ゲームが受け取ることはありません。
  • 要望・不具合を送る：外部の入力フォーム（現在は GitHub の Issues）を別のページで開きます。そこに書いた内容は、そのサービスに送られ、そのサービスのプライバシーポリシーに従って扱われます。個人情報は書かないでください。

7. 削除のしかた

  • アカウントとクラウドの記録：本ゲームの「マイページ」→「アカウントを削除」で、パスワードを入力すると、サーバーからすぐに削除されます（元に戻せません）。番付に載っている記録も一緒に消えます。
  • 番付の記録：「番付」で「番付に参加する」を外すと、番付からすぐに消えます。
  • 端末の記録：ホーム最下部の「記録と設定」→「記録を消す」で戦績を消せます。すべて消すには、ブラウザのサイトデータを削除するか、アプリをアンインストールしてください。
  • パスワードを忘れて削除できない場合は、下のお問い合わせ先からユーザー名を添えてご連絡ください。

8. お子さまの利用

本ゲームは、個人を特定できる情報を集めません。13歳未満の方がアカウントを作るときは、保護者の方と一緒に行ってください。

9. お問い合わせ・改定

お問い合わせは、Google Play のアプリ情報に載っている連絡先、または GitHub の Issues までお願いします。

この方針を変えるときは、このページを更新してお知らせします。
